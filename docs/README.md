# 副业风险雷达交付包

本目录用于把「副业风险雷达」从产品需求、系统设计、开发拆解到首批数据入库资料串起来，方便交给系统设计人员和开发人员继续推进。

## 目录结构

- `product/requirements-breakdown.md`：产品人员视角的需求拆解、用户场景、范围边界和优先级。
- `product/audit-policy.md`：站在审核者视角形成的内容、广告、隐私、AI 输出边界。
- `product/handoff-and-risk-register.md`：产品到系统设计、开发的交接说明，以及未决策项和风险登记。
- `design/system-design.md`：系统设计人员可用的模块、架构、页面流、状态流转和关键规则。
- `design/api-data-spec.md`：接口、数据表、字段和枚举设计。
- `dev/development-backlog.md`：开发任务拆解、里程碑、验收标准和测试样例。
- `data/content-sources.md`：可追溯资料来源和入库依据。
- `data/projects.seed.json`：首批项目风险卡种子数据，可作为项目库初始导入。
- `data/risk-keywords.seed.json`：首批风险词和规则数据，可作为检测引擎初始导入。
- `data/project-card-template.md`：运营维护项目卡时使用的模板。

## 当前产品结论

产品不做「赚钱套路大全」，而做「副业/兼职风险识别工具」。核心功能是：

1. 查项目：搜索副业或网络兼职名称，查看风险卡。
2. 测文案：粘贴兼职广告文案，识别可疑点和风险等级。
3. 做适配：根据时间、技能、预算和沟通意愿，给出低风险验证方向。
4. 看榜单：高危套路、谨慎验证项目、低成本可验证项目。

## 第一阶段不做

- 不做收费、课程、社群和导师撮合。
- 不做招聘、接单撮合和交易。
- 不做用户公开发布内容。
- 不做项目收益承诺和收益截图展示。
- 不做灰产、刷单、跑分、博彩、搬运侵权教程。

## 推荐开发顺序

1. 先做静态项目库、搜索、详情页。
2. 再做规则版文案风险检测。
3. 接入 AI 只做解释补充，不做最终判定。
4. 灰度测试后补充内容和误判修正。
5. 流量稳定后再接合规广告。
