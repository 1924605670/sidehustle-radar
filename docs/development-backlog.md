# 开发任务拆解

## 1. 推荐技术路线

### 方案 A：微信小程序原生 + 微信云开发

适合快速 MVP：

- 小程序原生开发。
- 云函数作为 API。
- 云数据库存项目卡、风险词、搜索日志、反馈。
- 云存储暂时不用。
- 后续接广告组件。

优点：部署简单、微信生态审核路径清晰。  
缺点：后续跨端能力弱。

### 方案 B：uni-app + Node.js API + MySQL/Supabase

适合后续扩展 H5：

- uni-app 输出微信小程序。
- Node.js 后端提供 API。
- MySQL/PostgreSQL 存储数据。
- 管理后台可复用 Web 技术。

优点：扩展性好。  
缺点：MVP 搭建成本略高。

建议第一版选方案 A，除非已经有现成后端团队。

### M2：规则版文案风险检测

目标：用户能粘贴兼职文案并得到风险结果。

任务：

- [x] 导入 `data/risk-keywords.seed.json`。
- [x] 实现文本清洗：
  - 全角半角统一。
  - 大小写统一。
  - 去除多余空格。
- [x] 实现关键词规则匹配。
- [x] 实现组合规则匹配。
- [x] 实现风险分计算。
- [x] 实现等级锁定。
- [x] 检测页：
  - 文本输入
  - 字数限制
  - 示例文案
- [x] 结果页：
  - 风险分
  - 命中规则
  - 可疑点解释
  - 建议动作
  - 相似真实案例
- [x] 只保存匿名统计，不保存原文。

验收样例：

文案：

> 点赞关注日结300，导师带单，下载APP完成任务返佣，后续可升级高佣任务。

期望：

- 风险等级：极高或高。
- 命中：日结、导师带单、下载APP、做任务返佣。
- 建议包含：不要垫资、不要下载陌生 App、不要提供验证码。

### M3：AI 辅助解释

目标：提升解释质量，但不改变规则判定。

任务：

- 后端接入模型 API。
- 设计系统提示词。
- AI 输入只传必要文本和命中规则。
- AI 输出 JSON。
- 结果合并：
  - 规则风险等级为主。
  - AI 只补充 possible_pattern、explanation、suggested_actions。
- 安全过滤：
  - 不输出操作教程。
  - 不输出第三方联系方式。
  - 不输出收益承诺。

验收：

- 高危文案不会被 AI 降级。
- AI 不会解释如何刷单、跑分、搬运。
- AI 输出失败时，系统仍能使用规则结果。

### M4：适配测试

目标：用户能得到低成本验证方向。

任务：

- [x] 4 道选择题页面。
- [x] 规则映射推荐项目。
- [x] 结果页：
  - 推荐项目 3 个
  - 不建议项目 3 个
  - 7 天验证计划
  - 免责声明
- [x] 推荐项目只来自已发布项目库。

验收：

- 选择「会剪辑、每天1-2小时、不愿销售、预算低」应推荐剪辑、封面、排版等服务类项目。
- 不应推荐刷单、跑分、博彩等极高风险项目。

### M5：内容维护与运营后台

目标：运营可持续维护数据。

MVP 可先做简易后台或使用数据库管理界面。

任务：

- 项目卡增删改查。
- 风险词增删改查。
- 搜索无结果词查看。
- 用户反馈查看。
- 项目状态：draft/reviewing/published/archived。
- 风险词状态：enabled/disabled/testing。

验收：

- 运营能下线一个项目卡。
- 运营能停用一个误判风险词。
- 搜索无结果词能被记录。

### M6：提审与灰度

目标：准备微信小程序提审。

任务：

- 完成隐私政策。
- 完成用户协议。
- 完成免责声明。
- 完成关于我们。
- 检查所有文案。
- 关闭广告组件。
- 准备测试账号或说明。
- 灰度给 50-100 名用户。

验收：

- 无强制登录。
- 无强制分享。
- 无加群引流。
- 无收益承诺。
- 无用户公开发布内容。
- 隐私政策与实际采集一致。

## 4. 关键测试用例

### 4.1 高危刷单样例

输入：

> 招聘点赞员，日结300-500，无需经验，导师带单，下载APP做任务返佣。

期望：

- 风险等级：极高。
- 命中规则：日结、无需经验、导师带单、下载APP、做任务返佣。
- 建议：不要垫资、不要下载陌生 App、不要提供验证码。

### 4.2 跑分样例

输入：

> 提供银行卡收款码，帮平台代收款刷流水，每天佣金800。

期望：

- 风险等级：极高。
- 命中规则：银行卡、代收款、刷流水。
- 建议：立即停止，不提供银行卡或收款码。

### 4.3 中风险短剧样例

输入：

> 短剧推广项目，教你剪辑挂链接，购买课程后提供素材和推广方法。

期望：

- 风险等级：中或高。
- 命中规则：课程收费、推广、素材。
- 建议：先核实授权，不购买承诺收益课程。

### 4.4 低风险服务样例

输入：

> 招长期视频剪辑合作，按条结算，提供素材和脚本，试剪一条后报价。

期望：

- 风险等级：低或中。
- 不应误判为极高。
- 建议：明确试剪是否付费、修改次数和结算方式。

## 5. 开发注意事项

- 不要把广告接入放在首版提审前。
- 不要做用户发布项目功能。
- 不要默认保存用户检测原文。
- 不要把 AI 结果作为唯一判断。
- 不要在前端暴露模型 API Key。
- 不要让高危项目详情页出现「如何操作」内容。
- 项目详情页所有外部链接先不开放跳转，避免审核不确定性。
