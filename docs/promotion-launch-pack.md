# 副业避坑雷达推广启动包

更新时间：2026-05-23

## 推广定位

副业避坑雷达不是“赚钱项目推荐器”，而是“副业广告风险判断工具”。所有推广内容都要围绕一个承诺：帮用户在付钱、转账、下载陌生 App、加入所谓导师群之前，先判断风险。

## 首周目标

- 让 100 个真实用户完成一次风险检测。
- 收集 30 个真实搜索词或用户提问。
- 找到 3 个转发意愿最强的内容选题。
- 验证结果页分享率是否能达到 5%。

## 渠道优先级

1. 微信私域
   - 朋友圈、微信群、熟人转发。
   - 重点话术：看到副业广告先测一下，不要先交钱。
   - 目标：拿第一批真实反馈和搜索词。

2. 小红书
   - 适合做“避坑清单”和“真实套路拆解”。
   - 标题要具体：不要写“副业避坑神器”，要写“看到这 6 个词，兼职大概率要你先交钱”。

3. 抖音/视频号
   - 适合 30-45 秒短视频。
   - 结构：一句高危话术开场 -> 拆风险信号 -> 引导用小程序测文案。

4. 头条/公众号
   - 适合长文沉淀和搜索流量。
   - 内容方向：近期案例拆解、常见副业话术词典、低成本核验清单。

## 每日复盘指标

- `project_search`：用户搜了什么方向。
- `risk_scan_success`：每天检测完成次数。
- `result_view`：结果页曝光量。
- `share_result`：结果页分享意愿。
- `copy_result_conclusion`：用户是否愿意把结论带走。
- `result_feedback_inaccurate`：判断不准的比例。
- 搜索空结果：决定后续补哪些项目和案例。

## 禁止话术

- 不说“帮你赚钱”。
- 不说“靠谱副业推荐”。
- 不说“保证避坑”。
- 不引导用户加入收费群。
- 不展示夸张收益截图。
- 不暗示能替代法律、警方、平台判断。
