# 持续收录计划

本计划用于持续扩充「副业避坑雷达」的项目库、风险案例库和规则词库。目标不是收集“赚钱项目大全”，而是持续沉淀用户会搜索、会遇到、会误判的副业/兼职风险信息。

## 1. 收录目标

### 1.1 三个月目标

- 项目库：从 30 个扩到 80-100 个。
- 案例库：从 17 个扩到 120-150 个。
- 每个高危项目至少 3 个案例。
- 每个中风险项目至少 1 个案例或平台规则依据。
- 每个低风险项目至少补齐真实门槛、交付物、核验步骤和不适合人群。

### 1.2 长期目标

- 覆盖用户常见搜索词：副业、兼职、网赚、自媒体、AI 变现、接单、电商、问卷、推广、课程、直播、本地服务。
- 每周新增候选项目 10-20 个。
- 每周入库项目 5-8 个。
- 每周入库案例 10-15 个。
- 每月复审高访问项目和高风险规则一次。

## 2. 内容分层

### 2.1 项目卡

用于回答“这个副业到底是什么、风险多高、能不能碰”。

必须包含：

- 项目名称和别名。
- 分类、风险等级、风险分。
- 一句话结论。
- 赚钱逻辑。
- 时间、技能、资金、资源门槛。
- 适合/不适合人群。
- 常见坑点。
- 低成本核验步骤。
- 红线提醒。
- 来源引用。

### 2.2 案例卡

用于回答“类似事情真实发生过什么”。

必须包含：

- 公开来源名称。
- 公开来源链接。
- 事件时间。
- 具体过程摘要。
- 损失、判罚、处置或平台处罚结果。
- 关联项目。
- 风险点。
- 给用户的一句话判断。

### 2.3 规则词

用于风险检测。

必须包含：

- 关键词或组合表达。
- 风险类别。
- 分值。
- 是否强制风险等级。
- 命中解释。

## 3. 采集来源

### 3.1 优先来源

这些来源可信度高，可直接作为入库候选：

- 公安、反诈中心、网警、地方公安公众号或政府网站。
- 最高人民检察院、最高人民法院、中国法院网、法院公众号。
- 工信部、网信办、市场监管总局、教育部、人社部等部门公开提醒。
- 微信、抖音、快手、小红书、B站、淘宝、拼多多、闲鱼等平台规则与治理公告。
- 新华网、央视网、人民网、中国新闻网、央广网、法治日报、人民法院报等主流媒体。

### 3.2 辅助来源

只用于发现线索，不直接入库为事实依据：

- 小红书、抖音、B站、知乎、贴吧、微博中的高频讨论。
- 招聘平台、接单平台、电商平台中的岗位和服务描述。
- 课程广告、社群广告、信息流广告截图。

辅助来源必须二次核验，不能直接写成案例。

## 4. 每周采集主题

### 第 1 周：高危网络兼职

重点词：

- 刷单返利、点赞日结、关注日结、任务返佣、垫资抢单、刷流水、跑分、代收款、代实名、注册卡、收款码。

目标：

- 每类至少补 2-3 个公开案例。
- 补充组合规则词。

### 第 2 周：求职与培训陷阱

重点词：

- 招转培、招转贷、付费内推、实习内推、就业包过、陪跑接单、资料费、保证金、押金、兼职打字员、聊天员。

目标：

- 补齐招转培、付费内推、打字员、聊天员等项目案例。
- 增加“求职类先收费”规则。

### 第 3 周：自媒体与内容变现

重点词：

- 小说推文、短剧推广、短视频矩阵、视频搬运、无人直播、数字人直播、切片授权、素材授权、伪原创、AI 文案投稿。

目标：

- 补齐版权、平台封禁、素材授权案例。
- 区分“合规内容服务”和“违规搬运/刷量”。

### 第 4 周：AI 与电商副业

重点词：

- AI 商品图、AI 模特、AI 绘本、AI 配音、AI 克隆声音、数字人、跨境无货源、店群、ERP 铺货、虚拟资料售卖。

目标：

- 补齐 AI 版权、肖像、声音、平台规则案例。
- 补齐电商无货源和虚拟资料售卖的真实门槛。

### 第 5 周：低风险可验证服务

重点词：

- 视频剪辑接单、简历优化、PPT 模板、公众号排版、本地商家短视频、资料整理、小红书封面、AI 商品图制作。

目标：

- 补充不是“高危”的可验证方向。
- 重点写清门槛、交付物、获客难点、低成本验证步骤。

## 5. 入库审核标准

### 5.1 可以入库

- 有官方、司法、平台或主流媒体来源。
- 能说明具体风险机制。
- 能给用户明确核验动作。
- 不包含联系方式、群二维码、课程链接。
- 不输出灰产操作步骤。

### 5.2 暂缓入库

- 只有社媒传闻，没有公开可信来源。
- 只有“我被骗了”的个人叙述，无法验证。
- 项目本身合法但缺少足够风险解释。
- 标题党、情绪化内容过重。

### 5.3 禁止入库

- 兼职广告、课程广告、接单推广。
- 收益截图、收款截图、招商加盟话术。
- 详细违法操作教程。
- 个人隐私、手机号、微信号、银行卡、身份证等敏感信息。

## 6. 数据维护流程

### 6.1 候选池

每次采集先进入候选池，不直接进正式数据。

候选字段：

```json
{
  "candidate_id": "cand_20260523_001",
  "type": "project|case|rule",
  "title": "候选标题",
  "source_name": "来源名称",
  "source_url": "来源链接",
  "found_at": "2026-05-23",
  "keywords": ["关键词"],
  "risk_categories": ["payment_first"],
  "summary": "为什么值得收录",
  "review_status": "pending"
}
```

### 6.2 初审

初审只判断三件事：

- 来源是否可信。
- 是否有具体事件或规则依据。
- 是否符合小程序审核边界。

### 6.3 入库

入库时分别更新：

- `data/projects.seed.json`
- `data/cases.seed.json`
- `data/risk-keywords.seed.json`
- `docs/content-sources.md`

入库后必须运行：

```bash
npm run validate:data
npm test
python3 -m py_compile server/*.py server/tests/*.py
```

### 6.4 复核

每月复核：

- 是否有失效链接。
- 是否有风险等级过高或过低。
- 是否有案例和项目不匹配。
- 是否有可能影响微信审核的表达。

## 7. 优先补充清单

### 7.1 高优先级项目

- TikTok 跨境短视频剪辑。

- 小红书代运营。
- 小红书蒲公英接单。
- 探店达人。
- 短视频切片授权。
- 数字人直播带货。
- AI 绘本制作。
- AI 小说代写。
- AI 论文润色。
- AI 简历代写。
- AI 商品图批量生成。
- 闲鱼无货源。
- 拼多多店群。
- 淘宝蓝海虚拟品。
- 视频号带货。
- 私域陪跑课程。
- 社群团购团长。
- 游戏搬砖。
- 手游代练。
- 数据标注。
- 问卷调查。
- 快递驿站兼职。
- 社区地推。
- 家教/陪诊/宠物喂养等本地服务。

### 7.2 高优先级案例缺口

优先补齐这些项目的案例：

- 小说推文。
- 短剧推广。
- 海外问卷。
- 跨境无货源。
- 小红书/短视频矩阵。
- 虚拟资料售卖。
- PPT 模板售卖。
- 简历优化。
- 本地商家短视频服务。
- 数据标注。
- 游戏搬砖。

### 7.3 规则词缺口

优先补充这些组合规则：

- `押金|保证金|资料费 + 入职|接单|派单`
- `下载APP + 返佣|抢单|提现|导师`
- `银行卡|收款码 + 代收款|刷流水|跑分`
- `内推|实习 + 保录|包过|付费`
- `课程|训练营 + 包接单|包变现|保底`
- `切片|搬运|去水印 + 变现|带货`
- `AI声音|克隆声音 + 商用|授权`
- `无货源|店群 + 包出单|零成本`

## 9. 衡量指标

- 项目覆盖数。
- 每个高危项目平均案例数。
- 无案例项目数。
- 搜索无结果词数量。
- 检测结果点击案例比例。
- 用户反馈中“找不到项目”的比例。
- 失效来源链接数。
