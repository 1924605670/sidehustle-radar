# 内容来源与入库依据

本文件用于记录项目库和风险词库的资料来源。运营人员新增项目卡时，应尽量引用官方、平台规则或可信公开资料，并在项目卡的 `source_refs` 中填写对应 ID。

持续收录的执行计划见 `docs/content-collection-plan.md`。

## S001 公安部：十大高发电信网络诈骗类型

- 链接：https://www.tlf.gov.cn/tlfs/c106653/202406/e204c4f7d902454ea20e9754b4a6dee3.shtml
- 类型：官方反诈资料
- 可沉淀规则：
  - 刷单返利类诈骗属于高发类型。
  - 虚假网络投资理财、虚假购物服务、冒充电商物流客服等均可作为相关风险参考。
  - 对“先小额返利建立信任、后诱导大额投入”的套路应设为高危。

## S002 网络信息内容生态治理规定

- 链接：https://www.gov.cn/gongbao/content/2020/content_5492511.htm
- 类型：内容合规
- 可沉淀规则：

  - 内容治理需要建立审核、处置和投诉反馈机制。
  - 对 UGC 应谨慎，MVP 阶段不做前台公开发布。

## S003 中华人民共和国个人信息保护法

- 链接：https://www.npc.gov.cn/npc/c2/c30834/202108/t20210820_313088.html
- 类型：隐私合规
- 可沉淀规则：
  - 个人信息处理应限于实现处理目的的最小范围。
  - 风险检测默认不保存用户粘贴原文。
  - 如开启历史记录，应明确告知并提供删除能力。

## 案例库来源

案例数据维护在 `data/cases.seed.json`，字段包括 `source_name`、`source_url`、`event_date`、`loss_or_consequence` 和 `risk_points`。MVP 已覆盖刷单返利、跑分、代实名、招转培、境外高薪、视频搬运、无人直播、AI 声音/图片、AI 副业课程、虚拟币、打字员兼职、聊天员兼职、博彩代理等方向。

当前案例优先引用以下公开来源：

- 公安/反诈机关：深圳大鹏新区公安分局、张家港市公安局等。
- 司法机关：最高人民检察院、中国法院网及法院消息转载。
- 主流媒体：新华社/新华网、央视网、中国新闻网、央广网、浙江在线等。
- 平台治理材料：用于补充无人直播、搬运、内容合规等平台规则风险。

新增案例时的最低要求：

- 必须有可访问的公开来源链接。
- 必须写清具体事件、损失或处置结果。
- 必须关联至少一个 `related_project_ids` 或两个以上 `related_categories`。
- 不使用无法核验的自媒体爆料、课程广告或营销号内容。

## 运营使用说明

新增项目卡时，至少满足以下一项：

- 能对应到官方公开的风险类型。
- 能对应到平台规则中的禁止行为。
- 能解释清楚商业逻辑、门槛和风险。
- 只作为“待验证/谨慎了解”呈现，不做收益承诺。

不满足以上条件的项目，不建议入库。
